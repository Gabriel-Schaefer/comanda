# Comanda Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir o backend Django (REST + WebSocket), a estrutura inicial do frontend React e os guias de aprendizado para que o Gabriel escreva o frontend do Comanda (cardápio digital + KDS em tempo real).

**Architecture:** Monorepo com `api/` (Django + DRF + Channels, PostgreSQL via Docker) e `web/` (Vite + React + TypeScript). Toda escrita passa pela API REST; o servidor avisa as telas por WebSocket depois que a transação é confirmada. O frontend é escrito pelo Gabriel, lição a lição, seguindo `docs/guia/`.

**Tech Stack:** Python 3.14, Django 6.0, DRF, Django Channels, Daphne, psycopg 3, dj-database-url, WhiteNoise, pytest-django, pytest-asyncio · Node 24, Vite, React, TypeScript, Tailwind CSS 4, React Router 7, TanStack Query 5, Vitest, Testing Library · Docker Compose (PostgreSQL 17).

**Spec:** `docs/superpowers/specs/2026-09-28-comanda-design.md`

## Global Constraints

- Idioma: nomes de domínio, mensagens de erro e textos de interface em português (ex.: `Pedido`, `mesa`, `"Produto inexistente ou indisponível."`).
- Preços são `Decimal` no banco; o JSON da API usa números (`COERCE_DECIMAL_TO_STRING = False`).
- `total`, `preco_unitario` e preços de adicionais são calculados no servidor; preços enviados pelo cliente são ignorados.
- Status só avança: `NOVO → EM_PREPARO → PRONTO → ENTREGUE`. Transição fora da ordem → 409.
- Validação (400): itens vazios; `mesa` fora de 1–999; `quantidade` fora de 1–20; produto inexistente ou inativo; adicional de outro produto ou repetido; observação > 200 caracteres.
- Avisos WebSocket saem com `transaction.on_commit`. O WebSocket só envia do servidor para o navegador.
- WebSocket aceita apenas as origens em `CORS_ALLOWED_ORIGINS`.
- Channel layer: `InMemoryChannelLayer` (limitação de processo único documentada no README).
- Frontend: nada de código de componente/hook entregue pronto; só scaffold, configuração, tipos da API e trechos de sintaxe nova nos guias.
- Comandos neste plano são para PowerShell no Windows, a partir da raiz `C:\Users\Khunrie\Desktop\Projetos\comanda`.
- Se uma versão fixada em `requirements.txt` não instalar no Python 3.14, subir para a menor versão compatível e registrar no commit.

## Review Focus

- Duas telas do KDS clicam "avançar" ao mesmo tempo → a segunda recebe 409, o pedido não pula etapa (teste na Task 5: `test_segundo_clique_igual_retorna_409`; `select_for_update` no serviço).
- Valores estranhos de mesa (`0`, `1000`, `"abc"`) → 400, nunca 500 (teste na Task 4, casos `mesa_*`).
- Adicional repetido `[7, 7]` → 400 em vez de cobrar em dobro (teste na Task 4, caso `adicional_repetido`).
- Preço do produto muda depois do pedido → pedido antigo mantém preço e total (teste na Task 4: `test_pedido_guarda_copia_do_preco`).
- Conexão WebSocket de origem desconhecida → recusada; totais em `Decimal` chegam como número no WebSocket sem quebrar a serialização (testes na Task 6).

```python
from decimal import Decimal

from django.core.validators import MinValueValidator
from django.db import models

PRECO_MINIMO = [MinValueValidator(Decimal("0"))]


class Categoria(models.Model):
    nome = models.CharField(max_length=60)
    ordem = models.PositiveIntegerField(default=0)

    class Meta:
        ordering = ["ordem", "nome"]

    def __str__(self):
        return self.nome


class Produto(models.Model):
    categoria = models.ForeignKey(Categoria, on_delete=models.PROTECT, related_name="produtos")
    nome = models.CharField(max_length=100)
    descricao = models.TextField(blank=True)
    preco = models.DecimalField(max_digits=8, decimal_places=2, validators=PRECO_MINIMO)
    imagem_url = models.URLField(blank=True)
    ativo = models.BooleanField(default=True)

    class Meta:
        ordering = ["nome"]

    def __str__(self):
        return self.nome


class Adicional(models.Model):
    produto = models.ForeignKey(Produto, on_delete=models.CASCADE, related_name="adicionais")
    nome = models.CharField(max_length=60)
    preco = models.DecimalField(max_digits=8, decimal_places=2, validators=PRECO_MINIMO)

    class Meta:
        ordering = ["nome"]
        verbose_name_plural = "adicionais"

    def __str__(self):
        return f"{self.nome} ({self.produto.nome})"
```

```python
from decimal import Decimal

from django.db import transaction

from .models import ItemPedido, ItemPedidoAdicional, Pedido


def pedidos_com_itens():
    return Pedido.objects.prefetch_related("itens__adicionais")


@transaction.atomic
def criar_pedido(mesa: int, itens: list[dict]) -> Pedido:
    pedido = Pedido.objects.create(mesa=mesa)
    total = Decimal("0")

    for dados in itens:
        produto = dados["produto"]
        item = ItemPedido.objects.create(
            pedido=pedido,
            produto=produto,
            nome_produto=produto.nome,
            preco_unitario=produto.preco,
            quantidade=dados["quantidade"],
            observacao=dados["observacao"],
        )
        preco_adicionais = Decimal("0")
        for adicional in dados["adicionais"]:
            ItemPedidoAdicional.objects.create(
                item=item, adicional=adicional, nome=adicional.nome, preco=adicional.preco
            )
            preco_adicionais += adicional.preco
        total += (produto.preco + preco_adicionais) * dados["quantidade"]

    pedido.total = total
    pedido.save(update_fields=["total"])
    return pedido
```

```python
class ItemEntradaSerializer(serializers.Serializer):
    produto_id = serializers.IntegerField()
    quantidade = serializers.IntegerField(min_value=1, max_value=20)
    adicionais = serializers.ListField(child=serializers.IntegerField(), required=False, default=list)
    observacao = serializers.CharField(max_length=200, required=False, allow_blank=True, default="")

    def validate(self, dados):
        try:
            produto = Produto.objects.get(pk=dados["produto_id"], ativo=True)
        except Produto.DoesNotExist:
            raise serializers.ValidationError({"produto_id": "Produto inexistente ou indisponível."})

        ids = dados["adicionais"]
        if len(ids) != len(set(ids)):
            raise serializers.ValidationError({"adicionais": "Adicional repetido."})
        adicionais = list(produto.adicionais.filter(pk__in=ids))
        if len(adicionais) != len(ids):
            raise serializers.ValidationError({"adicionais": "Adicional não pertence a este produto."})

        return {
            "produto": produto,
            "quantidade": dados["quantidade"],
            "adicionais": adicionais,
            "observacao": dados["observacao"].strip(),
        }
```

```python
class TransicaoInvalida(Exception):

@transaction.atomic
def avancar_status(pedido_id: int, novo_status: str) -> Pedido:
    pedido = Pedido.objects.select_for_update().get(pk=pedido_id)
    if PROXIMO_STATUS.get(pedido.status) != novo_status:
```
